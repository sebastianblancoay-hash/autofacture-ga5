# AutoFacture — maqueta GA5

Maqueta académica del proceso interno de recepción, revisión, asignación, seguimiento y reportes de facturas del proyecto AutoFacture.

## Abrir y recorrer

Descarga el código y abre `index.html` con un navegador. Para editarlo, abre la carpeta en Visual Studio Code. Consulta [LEEME.md](LEEME.md) para el recorrido y los controles de teclado.

La maqueta contiene seis páginas HTML y CSS propio, sin JavaScript ni dependencias. Todos los datos son ficticios; la asignación muestra un resultado fijo y el acceso comprueba campos, sin autenticar. Las ayudas explican las simulaciones.
