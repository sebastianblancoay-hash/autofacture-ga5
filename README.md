# AutoFacture — maqueta GA5

Maqueta académica del proceso interno de recepción, revisión, asignación, seguimiento y reportes de facturas del proyecto AutoFacture.

## Abrir y recorrer

[Recorrer la maqueta publicada](https://sebastianblancoay-hash.github.io/autofacture-ga5/).

También puedes descargar el código y abrir `index.html` con un navegador. Para editarlo, abre la carpeta en Visual Studio Code. Consulta [LEEME.md](LEEME.md) para el recorrido y los controles.

La maqueta contiene seis páginas HTML y CSS propio, sin JavaScript ni dependencias. Todos los datos son ficticios. La asignación muestra un resultado fijo y el acceso comprueba campos, sin autenticar usuarios.

[Visor auxiliar de anchos](https://sebastianblancoay-hash.github.io/autofacture-ga5/verificacion/visor_adaptable.html): muestra los HTML reales dentro de un marco de ancho fijo mediante HTML y CSS, sin JavaScript. Es un recurso de comprobación fuera del recorrido del producto; no representa un dispositivo físico.
